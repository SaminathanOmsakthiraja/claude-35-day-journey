## 🧠 What I Learned Today

### 1. Claude is more than a chatbot
A useful way to think about Claude is as an AI system that can assist throughout the development lifecycle.

```text
Idea
  ↓
Research
  ↓
Planning
  ↓
Implementation
  ↓
Debugging
  ↓
Testing
  ↓
Documentation
```

The goal is not to blindly delegate all of these tasks to AI. The goal is to understand where AI can assist and where human judgment is still required.

### 2. Prompting is only one part of effective AI usage
Good AI interaction isn't only about writing a clever prompt. The quality of the result also depends on the context provided to the model.

A useful mental model:

```text
Context
   +
Task
   +
Constraints
   +
Expected Output
   ↓
Better AI Interaction
```

This led me to the concept of context engineering, which I will explore more deeply in the coming days.

### 3. AI should be treated as a development partner
Instead of:

```text
Give me the solution.
```

A better development workflow can be:

```text
Understand
    ↓
Plan
    ↓
Implement
    ↓
Test
    ↓
Review
    ↓
Improve
```

This approach keeps the developer involved in the process instead of simply accepting generated output.

---

## 🧪 First Experiment
I tested different ways of asking Claude to help with a programming task.

### Basic approach

```text
Solve this programming problem.
```

### Context-aware approach

```text
I'm preparing for software development interviews.

Review my approach to this programming problem.

Don't immediately provide the solution.

First:
1. Identify whether my approach is logically correct.
2. Point out the first issue if it is incorrect.
3. Give me a hint.
4. Let me attempt the correction.
```

### Observation
The second approach changes the interaction from:

AI → Answer

to:

Developer ↔ AI → Problem Solving

That is the kind of interaction I want to develop throughout this journey.
