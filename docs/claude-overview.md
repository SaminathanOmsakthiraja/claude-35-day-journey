# Claude Overview

## What Claude is good at

Claude is especially useful for:

- code explanation and debugging
- summarizing technical material
- brainstorming and ideation
- planning workflows and project tasks
- reviewing written content
- assisting with technical learning

## What to watch out for

AI output should still be reviewed critically. The best workflow is:

1. Provide a clear task
2. Give useful context
3. Ask for structured reasoning
4. Validate results
5. Iterate based on evidence

## Effective usage mindset

Instead of asking only for final answers, ask Claude to:

- explain assumptions
- critique a proposed approach
- identify edge cases
- propose a plan
- point out risks before implementation

This keeps the human in the loop and produces better results.
